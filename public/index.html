Node.js FS Module

Shopping Cart Management Web Application

Welcome to the Shopping Cart Management Web Application homepage, served statically using the built-in Node.js fs module.

Application Features

  • Part A: Native Node.js HTTP Server running on http://localhost:3000
  • Part B: Express.js REST API Server running on http://localhost:4000
  • In-memory JavaScript array storage for shopping cart items
  • Full CRUD operations (Create, Read, Update, Delete)

Available Endpoints (HTTP Server - Port 3000)

  • GET / - Welcome HTML message
  • GET /cart - View all cart items in JSON format
  • GET /about - Application details
  • GET /home - Serves this static HTML file via FS module
  • POST /add-to-cart - Add a new item to cart
